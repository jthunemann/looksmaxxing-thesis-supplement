Supplementary Materials

Text Mining Looksmaxxing Forum Discourse

Interactive figures and aggregated results for a master thesis on publicly accessible English-language looksmaxxing forum threads.

Data availability and ethics note: This page does not contain raw forum text, usernames, thread URLs, thread IDs, direct quotes, images, or profile information. Only aggregated, deidentified results and visualisations are shared.

Project overview

This thesis examines dominant topics, sentiment patterns, and exploratory emotion signals in publicly accessible looksmaxxing forum discourse. The unit of analysis is the whole thread.

Analysis pipeline

  1. Collection of public forum threads
  2. Text cleaning and deidentification
  3. BERTopic topic modelling
  4. Manual topic validation and labelling
  5. RoBERTa-based sentiment analysis
  6. Exploratory multi-label emotion classification
  7. Aggregated visualisation of results

Interactive figures

The figures below present aggregated, deidentified outputs from the topic, sentiment, and emotion analyses. They do not contain raw forum text, thread URLs, thread IDs, usernames, or direct quotes.

Figure 1. Number of threads per BERTopic topic

This figure shows the number of threads assigned to each interpretable BERTopic topic. The BERTopic outlier category is excluded from the bars.

Figure 2. Sentiment distribution by BERTopic topic

This figure shows the percentage of threads classified as negative, neutral, or positive within each interpretable BERTopic topic. The BERTopic outlier category is excluded from the bars.

Figure 3. Emotion heatmap by BERTopic topic

This figure shows mean multi-label emotion-classification scores for each interpretable BERTopic topic. These scores indicate textual emotion signals and should not be interpreted as direct measures of users' emotional states. The BERTopic outlier category is excluded.

Figure 4. Topic similarity map

This figure shows the relative similarity of the interpretable BERTopic topics. Each point represents one topic, and point size indicates the number of threads assigned to that topic. Distances are based on average sentence-transformer embeddings for the threads within each topic. The BERTopic outlier category is excluded. Because the figure is a two-dimensional projection of high-dimensional topic representations, distances should be interpreted as approximate and exploratory rather than exact measurements.

Figure 5. Top c-TF-IDF terms per BERTopic topic

This figure shows the highest-scoring c-TF-IDF terms for each interpretable BERTopic topic. The dropdown menu can be used to switch between topics. Terms were used to support topic interpretation and labelling. The BERTopic outlier category is excluded.

Figure 6. Mean sentiment probabilities by BERTopic topic

This figure shows the average negative, neutral, and positive sentiment probabilities for each interpretable BERTopic topic. Unlike the sentiment distribution figure, which shows the dominant sentiment label, this figure displays the mean model probability for each sentiment category. The BERTopic outlier category is excluded.

Figure 7. Top emotion signal per BERTopic topic

This figure shows the highest-scoring emotion category for each interpretable BERTopic topic. The hover information also shows the second- and third-highest emotion scores. These scores indicate textual emotion signals and should not be interpreted as direct measures of users' emotional states. The BERTopic outlier category is excluded.

Figure 8. Topic similarity matrix

This figure shows pairwise cosine similarities between average topic embeddings for the interpretable BERTopic topics. Darker or higher-scoring cells indicate greater semantic similarity between topics. The diagonal represents each topic's similarity with itself and should not be interpreted. The BERTopic outlier category is excluded.

Figure 9. Emotion correlation heatmap

This figure shows exploratory correlations between multi-label emotion scores across all analysed threads. The correlations describe relationships between model-based textual emotion signals, not relationships between users' emotional states.
